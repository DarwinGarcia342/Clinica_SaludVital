# SaludVital

Sitio web para una clínica de salud llamada **SaludVital**. El proyecto usa HTML, CSS y JavaScript en archivos separados, además de imágenes SVG ubicadas en la carpeta `images`.

## Estructura

- `Html/Index.html` — página principal de la clínica.
- `Css/styles.css` — estilos visuales y diseño responsivo.
- `JavaScript/app.js` — comportamiento interactivo del menú y el formulario de contacto.
- `images/` — recursos gráficos usados por la página.

## Cómo usar

1. Abre `Html/Index.html` en el navegador.
2. Regístrate o inicia sesión en la sección de agenda.
3. Consulta la disponibilidad médica, agenda una cita, cancela o reprograma tu cita.
4. Revisa los recordatorios que se generan automáticamente en la app.

## Características

- Diseño limpio y profesional para una clínica.
- Navegación responsive con menú móvil.
- Registro de usuarios y acceso seguro.
- Agenda de citas médica en línea con selección de doctor, fecha y hora.
- Consulta de disponibilidad por especialista y fecha.
- Cancelación y reprogramación de citas desde el panel del usuario.
- Recordatorios automáticos simulados al correo cuando la cita está próxima.
- Animaciones suaves y secciones que aparecen al hacer scroll.
